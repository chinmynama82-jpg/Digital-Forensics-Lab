# Experiment 1: Evidence Acquisition Using FTK Imager

## Aim
To acquire volatile and non-volatile digital evidence using FTK Imager.

## Software Used
- FTK Imager
- Windows OS

## Procedure
1. Open FTK Imager.
2. Click **Capture Memory** to acquire RAM.
3. Save the `.mem` file.
4. Click **Create Disk Image**.
5. Select **Physical Drive**.
6. Choose image format (E01 or RAW).
7. Enter case information.
8. Select destination folder.
9. Enable **Verify images after they are created**.
10. Click **Start**.

## Result
Successfully acquired volatile and non-volatile evidence. Hash verification confirmed the integrity of the acquired image.
